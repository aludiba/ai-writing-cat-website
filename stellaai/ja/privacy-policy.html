Stella AI（「本アプリ」または「当社」）は AI 仮想キャラクター感情同伴アプリです。当社は、適用されるデータ保護法令（該当する場合、EU 一般データ保護規則および英国 GDPR（「GDPR」）、カリフォルニア州消費者プライバシー法（「CCPA」）、日本の個人情報保護法、韓国の個人情報保護法、中華人民共和国個人情報保護法を含みます）に従って個人情報を取り扱います。

利用前に必ずお読みください。特にチャットの第三者 AI 送信、天気用位置情報、カメラ/写真、アカウント削除、パスワード再設定。同意できない場合は利用を中止してください。

1. 収集する情報

  • メール・パスワード（ハッシュ）・ユーザー ID・任意のアバター
  • チャット本文・キャラ設定・気分記録・思い出・関係/章の進捗
  • 位置（任意・天気のみ。座標は Stella AI サーバーに保存しません）
  • カメラ/写真（アバター選択時のみ）
  • Apple IAP レシート・購読状態（Apple ID パスワードやカードは収集しません）
  • 端末・OS・アプリ版・言語/タイムゾーン・ネットワーク/IP・クラッシュログ

チャットに身分証・カード・パスワード等の機密を入力しないでください。

連絡先・SMS・通話・マイク・生体情報・広告 SDK/IDFA・広告計測 SDK は収集しません。

2. 利用目的

アカウント処理、AI 返信/章/挨拶生成、好感度・思い出・気分の表示、認可時の天気、購読検証、ローカル通知（リモートプッシュなし）、セキュリティ・法令対応、識別除去・集計による改善。チャット原文を当社モデル学習には使いません。

3. 保存と安全

チャット等は原則端末ローカル。クラウドはアカウント・アバター・購読記録のみ。クラウドデータは Supabase（Amazon Web Services インド・ムンバイ リージョン）に保存され、AI リクエストは阿里雲（Alibaba Cloud）上の当社中継サーバーを経由して中国本土の DeepSeek が処理します（第11条参照）。チャット本文は当社サーバーに保存しませんが、生成のため第三者 AI へリアルタイム送信します。アンインストール等でローカル履歴は復元できない場合があります。「パスワードを忘れた」は現行版で旧パスワードもメール認証コードも不要です。メール管理にご注意ください。

4. 共有と第三者

  • DeepSeek：チャット/文脈/プロンプト（api.hujiaofenwritingcat.top 経由）
  • Supabase：認証・ファイル・購読同期（Amazon Web Services インド・ムンバイ リージョン）
  • Apple：IAP/購読/復元。購読の検証では、Supabase 上の当社バックエンドが取引 ID と Apple 署名付き購読通知を阿里雲上の当社検証サーバーへ送信し、同サーバーが Apple に購読状態を照会して返します（同サーバーはデータを保存しません）。購読とアカウントの紐付けは Supabase に保存されます
  • Open-Meteo / BigDataCloud：認可時の緯度経度

個人情報は販売しません。法令に基づく開示や事業承継時の引継ぎがあり得ます。

11. 国際的なデータ移転

当社および委託先は複数の国で事業を行っています。機能に応じて、お客様の個人情報はお住まいの国以外に移転され処理される場合があります。

  • インド：アカウント・アバター・購読記録（Supabase、Amazon Web Services ムンバイ リージョン）
  • 中国本土：AI 生成のために送信されるチャット本文と文脈（阿里雲上の当社中継サーバーおよび DeepSeek）。当社サーバーにチャット本文は保存しません
  • その他の国：Apple（決済・購読）、天気・ジオコーディング事業者（Open-Meteo、BigDataCloud）。各社のポリシーに従います

これらの国は、お住まいの国と同等のデータ保護水準を有しない場合があります。法令上必要な場合、委託先との契約上のデータ取扱条件、通信の暗号化、データの最小化などの措置を講じ、必要に応じてお客様の同意に基づき移転します。AI チャットをご利用の際、メッセージは処理のため中国本土へ送信されますのでご留意ください。措置の詳細はお問い合わせください。
